# Configuration reference

## Configuration sources

| Source | Contains | Changes take effect |
| --- | --- | --- |
| Bootstrap YAML | Listeners, environment references, process and configuration limits, synchronization | Restart |
| PostgreSQL revision | Routes, targets, upstream transport/TLS, handlers, forwarding trust, metrics | Snapshot reload |
| Environment | DSNs, management/admin tokens, referenced upstream TLS material | Restart/recompile as documented |

YAML rejects routing sections, unknown/duplicate keys, nulls, aliases, and extra
documents. JSON imports reject unknown/duplicate keys and unsupported versions.
Configuration decoding checks typed values and required fields separately.
JSON is an import format, never an alternative runtime configuration source.

## Operational fields

Generated by `make docs` from the actual typed OpenAPI schemas. All fields are
available through full configuration GET/PUT/PATCH. Entity endpoints support
CRUD; target endpoints are `/v1/upstreams/{id}/targets/{target_id}`. Route binding
order is also exposed at `/v1/routes/{id}/handlers`.

The default column describes omission. `null` on nullable overrides removes the
override. PATCH `null` on optional non-nullable fields removes the field and restores
its omission default; removing a required field is rejected. Arrays replace as a
whole. Empty arrays are explicit values. Durations are strings in Go units, range
0s–24h; explicit 0s disables operational timeouts. Bootstrap timeouts must be positive.

Configured GET values retain omission; effective GET resolves transport, handler,
metrics, and route deadline defaults. Export configured values for re-import.
Secret values are never part of this contract: TLS fields name environment variables,
not PEM contents. Placeholder names such as `***` are invalid references.

Route definitions and incoming request paths reject literal percent characters.
Incoming `%25` and double encodings such as `%2525` return 400 before routing;
encoded spaces and valid Unicode are supported. Encoded separators, dot segments,
repeated slashes, and control characters are also rejected. This restriction is
about request paths; encoded percent characters in query values remain supported.

## Handler instance fields

- `enabled`: False removes this handler from the request chain. Required: no. Default: true.
- `id`: Unique instance identifier. minLength=1; maxLength=64; pattern `^[A-Za-z0-9_-]{1,64}$` Required: yes. Default: none / see description.
- `options`: Options are determined by the handler type; see the schemas below. Required: yes. Default: none / see description.
- `type`:  enum=['access_log'] Required: yes. Default: none / see description.
- `version`: Handler contract version. enum=[1] Required: yes. Default: none / see description.

document must be a non-null mapping. Omission selects these process defaults.

documents are rejected. No environment substitution is performed on YAML.

`limits` values bound publication and loading. Use identical `limits` on every `serve`
and `manage` process: a serving process with lower limits rejects a revision that
`manage` published, keeps its last valid snapshot, and becomes stale after
`config_sync.max_staleness`; a starting `serve` process fails its startup timeout.
Lower limits only after the active revision fits them. Route conflict checks scan
route pairs, so compilation time grows quadratically with routes; measure before raising
`max_entities` (see benchmarks.md#large-revision-publication).
The OpenAPI document served by `manage` reports its own limits; `docs/openapi.json`
shows the defaults.

All listener strings must differ. Valid syntax does not reserve a port; listener
conflicts and unreadable certificates are startup errors. `check` is offline and
does not read environment secrets or prove listener/database/backend availability.
